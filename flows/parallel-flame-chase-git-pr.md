# flame_chasoid:parallel_git_pr

Chase three leads at once, the way a team works a repository: every lane has a clone of its
own and opens pull requests, and a pull request reaches `main` only when your evaluator, run on
a clean tree, shows it improves on `main`. There is no reviewer, so it fits a task with a
number to beat and a command that measures it. Its setup is fixed to the one that did best in
a twelve-hour experiment.
